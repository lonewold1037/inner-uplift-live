# Memflect Dev Cheat Sheet

## Quick Git Commands
- `gcpi "message"` - Add all, commit, push (THE BIG ONE)
- `gs` - Check status
- `gl` - See last 10 commits
- `gd` - See what changed

## Render
- Logs: Dashboard → Service → Logs tab
- Shell: Dashboard → Service → Shell tab
- Force redeploy: Manual Deploy button

## Key Files
- Form: `app/views/reflections/_form.html.erb`
- Status: `app/views/reflections/_status_content.html.erb`
- Controller: `app/controllers/reflections_controller.rb`
